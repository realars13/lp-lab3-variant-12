# Лабораторная работа 3

Дисциплина «Методы оптимизации».

Размещение камер при бюджете. Мягкий Арсений Сергеевич. Группа 517, N=14, Y=26, вариант 12.

Из корневой папки комплекта установите зависимости `python -m pip install -r requirements.txt`, затем выполните `python run.py --lab 3`. Требуется Python 3.12.14; инструкции по виртуальному окружению находятся в `../README.md`.

Исходные координаты, видимость, цены и приоритеты — `data.json`, default_rng(10114). Дополнительные файлы `scale_10.json`, `scale_20.json`, `scale_40.json` используют seed = 10114+n. Генерация описана в `../generate_data.py` и отчёте; модель, проверки, эвристика и эксперименты находятся в `run.py`.

Читайте `REPORT.md` и `STAR_FORMULATIONS.md`. В `results/` сохранены LP- и MILP-планы, жадные планы, таблицы сценариев, формулировок и масштабов, независимые проверки каждого семейства решений, графики и логи. Сравнение формулировок использует дефицитный бюджет 37; бюджет исходной базы 47. В extended-векторах назначения следуют после камер и точек в порядке видимых пар (строка i, затем столбец j). Их значения дополнительно выгружены в `form_*_solution.csv`.
